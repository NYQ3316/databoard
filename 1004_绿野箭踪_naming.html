enter_game（单局游戏开始）
玩家确认开始一局游戏时触发（关卡 / 对战 / 练习三模式通用；支撑看板：热门模式分布、热门关卡排名、活跃账号）
属性名显示名类型说明示例来源
game_id游戏ID文本产品唯一编号1004必含
session_id会话ID文本本地生成 UUID v4（可不带横杠）；单局session_id保持一致，与对应 end_game 一致853b054e-1f29-4810-91d0-857471542101必含
timestamp时间戳时间事件发生时间（ISO8601，含时区+08:00）2026-05-26T09:35:00+08:00必含
game_type游戏模式文本本局游戏模式（数值型文本）：0=关卡模式 / 1=对战模式 / 2=练习模式0通用
level_id关卡ID文本关卡唯一标识（1~10，对应 6 主题及夜间变体；练习模式固定为 1）3通用
player_number游戏人数文本参与本局的玩家人数（关卡与练习 1~4，对战 2~4）2通用
📦 对象组字段：玩家信息封装在 user_info 对象组中（1~4 人时逐玩家各上报一条，user_info 内仅含本玩家数据）。
user_info 参与者信息 对象组 对象数组，每个对象包含 user_id（文本）与 position [{"user_id":135,"position":1},{"user_id":136,"position":2}] 项目特有
user_info.user_id↳ 人脸角色ID文本参与玩家ID（JSON 值为裸数字，类型按文本统计）
游客按位置号上报：位置1=-1 / 位置2=-2 / 位置3=-3 / 位置4=-4（与 position 位置号对应）		135项目特有
user_info.position↳ 玩家位置文本该玩家的位置号（数值型文本，对应 P1~P4）：1 / 2 / 3 / 41项目特有
end_game（单局游戏结束）
一局游戏自然结束（箭矢耗尽 / 时间耗尽 / 动物全部击败或离场）或玩家中途退出时触发（支撑看板：位置胜率分析、动物命中率分析、关卡明细表的星级占比 / 中途退出率 / 场均击杀 / 命中占比）

star_rating星级评分文本本局星级评分（数值型文本，依大纲 1~3 星）：0=未获得星级 / 1 / 2 / 3；仅关卡模式上报，对战与练习模式不上报2通用
📦 对象组字段：玩家信息（位置 / 获胜标记 / 得分）封装在 user_info 对象组中；本局动物命中明细封装在 animal_info 对象组中（user_info 逐玩家各一条，animal_info 逐动物各一条）。
user_info 参与者结算信息 对象组 对象数组，每个对象包含 user_id（文本）、position、is_win 与 score [{"user_id":135,"position":1,"is_win":1,"score":230},{"user_id":136,"position":2,"is_win":0,"score":150}] 项目特有
user_info.user_id↳ 人脸角色ID文本参与玩家ID（JSON 值为裸数字，类型按文本统计）
游客按位置号上报：位置1=-1 / 位置2=-2 / 位置3=-3 / 位置4=-4（与 position 位置号对应）		135项目特有
user_info.position↳ 玩家位置文本该玩家的位置号（数值型文本，对应 P1~P4）：1 / 2 / 3 / 4；与对应 enter_game 一致1项目特有
user_info.is_win↳ 是否获胜文本该玩家是否为本局获胜者（数值型文本）：1=获胜（排名第一） / 0=未获胜；仅对战模式上报，关卡与练习模式不上报1项目特有
user_info.score↳ 得分数值该玩家本局得分（整数）；对战模式用于排名（与 is_win 对应），关卡模式为个人命中得分汇总230项目特有
animal_info 动物命中明细 对象组 对象数组，本局每种被命中的动物各一条，每条包含 animal_id（文本）、appear_count、kill_count 与 weak_count [{"animal_id":3,"appear_count":18,"kill_count":13,"weak_count":4},{"animal_id":7,"appear_count":15,"kill_count":9,"weak_count":2}] 项目特有
animal_info.animal_id↳ 动物ID文本动物唯一标识（数值型文本，1~36，对应 6 主题各 6 种动物；名称由统计端按 Enemy 表映射）3项目特有
animal_info.appear_count↳ 出现数量数值本局该动物的出现（生成）数量18项目特有
animal_info.kill_count↳ 击杀数量数值本局该动物被击杀的数量（含普通命中与弱点击杀）13项目特有
animal_info.weak_count↳ 弱点击杀数量数值本局该动物被弱点命中击杀的数量（弱点命中得双倍积分）4项目特有
