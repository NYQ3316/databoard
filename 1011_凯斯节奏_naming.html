🎵 1011 凯斯节奏

埋点事件与属性定义  |  节奏音游
← 返回命名规范
游戏类型：节奏音游
游戏模式：曲库模式 / 段位模式
难度：简单 / 普通 / 困难
段位：青铜 / 白银 / 黄金 / 铂金 / 钻石
支持人数：1~2人

enter_game 进入游戏

玩家确认进入一局游戏时触发（含段位模式，通过 game_type 区分）
✅ 必含
属性名显示名类型说明示例来源
game_id游戏ID文本固定值 10111011通用
session_id会话ID文本单次启动唯一标识s_987654321通用
timestamp时间戳时间事件发生时间（Unix毫秒）2026-05-26T09:35:00+08:00通用
game_type游戏模式文本曲库模式 / 段位模式0=曲库模式通用
player_number游戏人数文本参与本局的玩家人数1 / 2通用
difficulty难度文本简单 / 普通 / 困难普通通用
song_id歌曲ID文本当前所选曲目编号曲目03通用
rank_level段位等级文本仅段位模式填写；青铜/白银/黄金/铂金/钻石黄金通用
📦 对象组字段：以下字段为封装在 user_info 对象组中的各角色明细数据， user_info 为对象数组，每个对象以 user_id（文本类型）标识角色， 包含该角色的各字段数据；对象组格式下所有字段值均为裸值（无引号），类型由标签承载。
user_info 各角色进入游戏数据 对象组 对象数组，每个对象包含 user_id（文本）及各角色的 skin_id [{"user_id":135,"skin_id":3},{"user_id":136,"skin_id":1}] 项目特有
user_info.skin_id 皮肤ID 数值 单个角色的皮肤ID 3 项目特有
user_info.user_id 角色ID 文本 参与游戏的角色ID 135 项目特有

📦 对象组字段：以下字段为封装在 user_info 对象组中的各角色明细数据， user_info 对象数组，每个对象以 user_id（文本类型）标识角色， 包含该角色的各字段数据；对象组格式下所有字段值均为裸值（无引号），类型由标签承载。
user_info 各角色游戏数据 对象组 对象数组，每个对象包含 user_id（文本）及各角色的 score / star_rating / combo_max [{"user_id":135,"score":68500,"star_rating":A,"combo_max":86},{"user_id":136,"score":52300,"star_rating":B,"combo_max":62}] 项目特有

user_info.combo_max 最高连击数 数值 单个角色本局最高连击次数 86 通用
user_info.user_id 角色ID 文本 参与游戏的角色ID 135 项目特有
