🏎️ 1025《体感卡丁车》事件与属性命名

体感竞速游戏 · 1~4人 · 挑战模式 / 大奖赛模式 · 事件共 5 个
enter_game（进入游戏）
玩家完成赛道、难度、角色、卡丁车选择后确认进入比赛时触发
属性名显示名类型说明示例来源
game_id游戏ID文本产品唯一编号1025必含
session_id会话ID文本单次对局唯一标识s_987654321必含
timestamp时间戳时间事件发生时间（Unix毫秒）2026-05-26T09:35:00+08:00必含
game_type游戏模式文本默认模式 / 杯赛模式0=默认 / 1=杯赛通用
player_count游戏人数文本1~4 人1 / 2 / 3 / 4通用
map_id赛道ID文本所选赛道唯一标识map_01（草原赛车场）项目特有
difficulty难度等级文本对应 50cc/100cc/150cc50 / 100 / 150通用
📦 对象组字段：以下字段为封装在 user_info 对象组中的各角色明细数据， user_info 为对象数组，每个对象以 user_id（文本类型）标识角色， 包含该角色的角色选择和卡丁车选择数据。
user_info 各角色配置数据 对象组 对象数组，每个对象包含 user_id（文本）及各角色的 role_id / kart_id [{"user_id":135,"role_id":role_01,"kart_id":kart_01},{"user_id":136,"role_id":role_02,"kart_id":kart_03}] 项目特有
user_info.user_id↳ 角色ID文本该玩家的人脸角色标识135项目特有
user_info.role_id↳ 车手ID文本该玩家所选车手role_01（小熊）通用
user_info.kart_id↳ 卡丁车ID文本该玩家所选卡丁车kart_01（闪电卡丁）项目特有
end_game（退出游戏 / 对局结束）
比赛自然结束（全部到达终点 / 超时）进入结算界面时触发
属性名显示名类型说明示例来源
game_id游戏ID文本产品唯一编号1025必含
session_id会话ID文本与 enter_game 同一 sessions_987654321必含
timestamp时间戳时间事件发生时间（Unix毫秒）2026-05-26T09:35:00+08:00必含
game_type游戏模式文本默认模式 / 杯赛模式0=默认 / 1=杯赛通用
player_count游戏人数文本1~4 人1 / 2 / 3 / 4通用
map_id赛道ID文本本局所用赛道map_01项目特有
difficulty难度等级文本本局所选难度50 / 100 / 150通用
📦 对象组字段：以下字段为封装在 user_info 对象组中的各角色明细数据， user_info 为对象数组，每个对象以 user_id（文本类型）标识角色， 包含该角色的名次、最佳圈速、平均圈速数据。
user_info 各角色结算数据 对象组 对象数组，每个对象包含 user_id（文本）及各角色的 player_rank / best_lap / avg_lap [{"user_id":135,"player_rank":1,"best_lap":72800,"avg_lap":90667},{"user_id":136,"player_rank":3,"best_lap":81500,"avg_lap":102300}] 项目特有
user_info.user_id↳ 角色ID文本该玩家的人脸角色标识135项目特有
user_info.player_rank↳ 玩家名次文本最终名次（1~8），未完成记 0"1"~"8" / "0"项目特有
user_info.best_lap↳ 最佳圈速数值该玩家本局单圈最快用时（毫秒）72800（1分12.8秒）项目特有
user_info.avg_lap↳ 平均圈速数值该玩家总用时÷圈数（毫秒）90667（1分30.67秒）项目特有
