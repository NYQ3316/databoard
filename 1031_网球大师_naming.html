🎾 1031《网球大师》事件与属性命名

体感网球 · 1~2人 · 单人生涯 / 双人合作 · 5 大杯赛（新手赛/进阶赛/技巧赛/精英赛/巅峰赛）
图例说明
必含 基础字段必填 通用 naming_standards.html 中已有定义（枚举按本项目重定义） 项目 1031 项目自定义字段
📌 本页严格对齐跨项目统一标准：基础必含字段（game_id / user_id / session_id / timestamp）与必含事件（enter_game / end_game / pause_game / continue_game）均沿用标准。
📌 含 user_info 对象组的事件，嵌套属性（含 user_id）只在对象组内出现，事件顶层不重复；无 user_info 的事件（pause_game / continue_game）保留顶层 user_id 列表。
enter_game（进入杯赛/比赛）
玩家确认进入某一杯赛的某一轮次比赛时触发。看板据此统计各杯赛各轮次「到达人次」与单/双人分布。
属性名显示名类型说明示例来源
game_id游戏ID文本产品唯一编号1031必含
session_id会话ID文本单次比赛唯一标识s_987654321必含
timestamp时间戳时间事件发生时间（Unix毫秒）2026-05-26T09:35:00+08:00必含
game_type杯赛ID文本杯赛编号，0=新手赛(免费) / 1=进阶赛(免费) / 2=技巧赛(付费) / 3=精英赛(付费) / 4=巅峰赛(付费)（通用 game_type 字段，本项目重定义为杯赛ID，取代原 cup_id；原「单/双人」含义由 player_number 承载）0项目
round_id杯赛轮次文本本场所在的淘汰轮次（数字型文本）：0=16强 / 1=8强 / 2=4强 / 3=半决赛 / 4=决赛（阶段式，参考 1083 写法）0 / 1 / 2 / 3 / 4项目
player_number游戏人数文本参与本局的玩家人数，1=单人生涯 / 2=双人合作（承载原 game_type 的单/双人含义）1 / 2通用
📦 对象组字段：以下字段封装在 user_info 对象数组中，每个对象以 user_id（文本类型）标识角色，包含该角色选用的角色与球拍。
user_info各角色数据对象组对象数组，每个对象包含 user_id（文本）、role_id（角色类型，数字型文本）及 item_type（球拍类型，数字型文本）[{"user_id":135,"role_id":"0","item_type":"0"},{"user_id":136,"role_id":"2","item_type":"4"}]项目
user_info.user_id角色ID文本参与游戏的人脸角色ID，若对手为 AI 则填 999135必含
user_info.role_id角色类型文本玩家选择的角色类型（数字型文本），4 类：0=全能型 / 1=灵巧型 / 2=力量型 / 3=技巧型0 / 1 / 2 / 3通用
user_info.item_type球拍类型文本玩家选用的球拍（数字型文本），7 款：0=标准网球拍 / 1=平底锅 / 2=咸鱼 / 3=大葱 / 4=光剑 / 5=仙女棒 / 6=棒棒糖0 / 1 / 2 / 3 / 4 / 5 / 6通用
end_game（杯赛/比赛结束）
一局杯赛自然结束时触发。看板据此统计各杯赛「晋级决赛 / 失败率 / 胜率」；角色与球拍的使用率（来自 enter_game）、胜率（本事件 winner 经 session_id 关联 enter_game 的角色/球拍）按杯赛分列。
