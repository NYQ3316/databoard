🏍️ 1034《巅峰骑士》事件与属性命名

体感摩托竞速 · 1~2人 · 关卡模式 / 无尽模式 · 事件共 4 个
enter_game（进入游戏 / 关卡开始）
玩家完成模式、难度、关卡选择并完成肢体绑定，倒计时结束后正式进入比赛时触发
属性名显示名类型说明示例来源

session_id会话ID文本单次对局唯一标识s_987654321必含
timestamp时间戳时间事件发生时间（Unix毫秒）2026-05-26T09:35:00+08:00必含
game_type游戏模式文本关卡模式 / 无尽模式0=关卡 / 1=无尽通用
player_count游戏人数文本1~2 人1 / 2通用
map_id赛道ID文本所选赛道/关卡唯一标识road_01（公路第1关）项目特有
difficulty难度等级文本0=简单 / 1=普通 / 2=困难0 / 1 / 2通用

📦 对象组字段：以下字段为封装在 user_info 对象组中的各角色结算数据， user_info 为对象数组，每个对象以 user_id（文本类型）标识角色， 包含该角色的难度、通关结果、碰撞次数数据。
user_info 各角色结算数据 对象组 对象数组，每个对象包含 user_id（文本）及各角色的 difficulty / result / hit_count [{"user_id":135,"difficulty":0,"result":1,"hit_count":3},{"user_id":136,"difficulty":0,"result":0,"hit_count":5}] 项目特有
user_info.user_id↳ 角色ID文本该玩家的人脸角色标识135项目特有
user_info.difficulty↳ 难度等级文本本局所选难度，0=简单 / 1=普通 / 2=困难0 / 1 / 2通用
user_info.result↳ 通关结果文本0=失败 / 1=通关成功0 / 1通用
user_info.hit_count↳ 碰撞次数文本本局碰撞车辆的总次数3项目特有
