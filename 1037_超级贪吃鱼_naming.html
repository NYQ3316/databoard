🐟 1037 超级贪吃鱼

埋点事件与属性定义  |  体感休闲派对对战
← 返回命名规范
游戏类型：体感休闲对战（派对模式）
基础模式：派对模式（1人/2~4人，不足AI补位）
支持人数：1~4人
核心指标：热门鱼类、热门地图、局内对抗（按名次吃/被吃）
通用属性（跨项目复用）
项目特有属性
✅ 必含 所有项目必须上报
⚪ 可选 按项目品类选用

enter_game 进入游戏

玩家确认进入一局派对模式对战时触发（含选择形象与场景）
✅ 必含
属性名显示名类型说明示例来源
game_id游戏ID文本固定值 10371037通用
session_id会话ID文本单次启动唯一标识s_987654321通用
timestamp时间戳时间事件发生时间（Unix毫秒）2026-05-26T09:35:00+08:00通用
game_type游戏模式文本派对模式（当前唯一基础模式）0=派对模式通用
player_number游戏人数文本参与本局玩家人数（不足由AI对手补位至4人）1 / 2 / 3 / 4通用
map_id场景地图ID文本本局选择的场景地图（整局共享）1=鱼缸, 2=池塘, 3=湖底, 4=大陆架, 5=浅海, 6=深海通用
📦 对象组字段：以下字段封装在 user_info 对象组中， user_info 为对象数组，每个对象以 user_id（文本类型）标识一名玩家， 包含该玩家选择的小鱼形象（skin_id）与出生位置（pos，1~4），取值须符合子属性原本的类型约束。
user_info 各玩家选择数据 对象组 对象数组，每个对象以 user_id（文本类型）标识一名玩家，包含其选择的小鱼形象与出生位置；对象组格式下所有字段值均为裸值（无引号），类型由标签承载 [{"user_id":135,"skin_id":0,"pos":1},{"user_id":136,"skin_id":1,"pos":2}] 项目特有
user_info.user_id 角色ID 文本 参与游戏的人脸角色ID（裸数字值，类型文本） 135 项目特有
user_info.skin_id 小鱼形象ID 文本 玩家选择的小鱼形象（用于区分玩家身份与看板「热门鱼类」统计） 0~3=初始4花色, 4~10=可解锁形象 通用
user_info.pos 出生位置 文本 玩家在本局中的出生位置编号（1~4），对应派对模式的 4 个出生点 1 / 2 / 3 / 4 项目特有

end_game 退出游戏

一局对战自然结束（3分钟倒计时耗尽）并结算时触发
✅ 必含
属性名显示名类型说明示例来源
game_id游戏ID文本固定值 10371037通用
session_id会话ID文本单次启动唯一标识s_987654321通用
timestamp时间戳时间事件发生时间（Unix毫秒）2026-05-26T09:38:00+08:00通用
game_type游戏模式文本派对模式（当前唯一基础模式）0=派对模式通用
player_number游戏人数文本参与本局玩家人数（不足由AI对手补位至4人）1 / 2 / 3 / 4通用
📦 对象组字段：以下字段封装在 user_info 对象组中， user_info 为对象数组，每个对象以 user_id（文本类型）标识一名玩家， 包含该玩家的鱼皮肤ID（skin_id）、出生位置（pos，1~4）、最终体型等级（size）、本局名次（player_rank）与对抗聚合数据，取值须符合子属性原本的类型约束。
user_info 各玩家结算数据 对象组 对象数组，每个对象以 user_id（文本类型）标识一名玩家，包含其鱼皮肤ID、出生位置、最终体型等级、名次与对抗聚合数据；对象组格式下所有字段值均为裸值（无引号），类型由标签承载 [{"user_id":135,"skin_id":0,"pos":1,"size":8,"player_rank":1,"eaten_wild_count":25,"eaten_player_count":3,"eaten_by_count":2},{"user_id":136,"skin_id":1,"pos":2,"size":5,"player_rank":3,"eaten_wild_count":18,"eaten_player_count":1,"eaten_by_count":4}] 项目特有
user_info.user_id 角色ID 文本 参与游戏的人脸角色ID（裸数字值，类型文本） 135 项目特有
user_info.skin_id 小鱼形象ID 文本 玩家选择的小鱼形象（用于区分玩家身份与看板「热门鱼类」统计） 0~3=初始4花色, 4~10=可解锁形象 通用
user_info.pos 出生位置 文本 玩家在本局中的出生位置编号（1~4），对应派对模式的 4 个出生点 1 / 2 / 3 / 4 项目特有
user_info.size 最终体型等级 数值 本局结束时玩家鱼的体型等级（1~15），胜负首要判定维度 8 项目特有
user_info.player_rank 本局名次 数值 玩家本局最终名次，0 表示未完成 1~4 / 0 通用
user_info.eaten_wild_count 吃野生鱼数 数值 本局吃掉野生小鱼的总数量 25 项目特有
user_info.eaten_player_count 吃玩家鱼数 数值 本局吃掉其他玩家鱼的总次数（看板「人均吃对手次数」数据源） 3 项目特有
user_info.eaten_by_count 被吃次数 数值 本局被其他玩家吃掉的次数（看板「人均被吃次数」数据源） 2 项目特有
