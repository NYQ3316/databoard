🌟 1061《奇妙萌可之闪耀流星》事件与属性命名

体感闯关 · 1~2人 · 故事 / 挑战(简单·普通·困难) · 18 关（关底萌可）
enter_game（进入关卡）
玩家确认进入某一关时上报。
属性名显示名类型说明示例来源
game_id游戏ID文本产品唯一编号1061必含
session_id会话ID文本单次游玩唯一标识s_987654321必含
timestamp时间戳时间事件发生时间（Unix毫秒）2026-05-26T09:35:00+08:00必含
game_type游戏模式文本通用 game_type 字段，本项目重定义枚举：0=故事 / 1=挑战（数字型文本）0 / 1通用
player_number游戏人数文本参与本局的玩家人数，1=单人 / 2=双人（数字型文本，复用通用 player_number）1 / 2通用
level_id关卡ID文本具体关卡标识，1~18（数字型文本，复用通用 level_id；关底萌可：1兔兔/2呼啦/3光明/4叮咚/5流浪/6动动/7贴贴/8熊熊/9缤缤·纷纷/10绵羊/11透明/12共共/13跳舞/14狐狐/15歌谣/16悄悄/17亲亲/18黑洞Boss）3通用
difficulty游戏难度文本通用 difficulty 字段，本项目重定义编码：0=简单 / 1=普通 / 2=困难（数字型文本）；仅挑战模式（game_type=1）有效，故事模式不上报0 / 1 / 2通用
📦 对象组字段：封装在 user_info 对象数组中，每个对象以 user_id（数值，裸数字，如 135，对齐示例）标识角色，并含该角色选用的皇室萌可（role_id，数字型文本）。
user_info各角色数据对象组对象数组，每个对象包含 user_id（数值，裸数字）与 role_id（皇室萌可，数字型文本）[{"user_id":135,"role_id":"0"},{"user_id":136,"role_id":"2"}]通用
user_info.user_id角色ID数值参与游戏的人脸角色ID（含 user_info 时只在对象组内出现，顶层不重复；裸数字，如 135，对齐示例）135必含
user_info.role_id皇室萌可文本玩家选用的皇室萌可（数字型文本），5 类：0=爱心 / 1=银光 / 2=星光 / 3=月光 / 4=极光（极光仅 18 关 + 挑战模式可用）。复用通用 role_id 字段，本项目重定义为皇室萌可0 / 1 / 2 / 3 / 4通用
end_game（关卡结束）
一关自然结束时上报。通关结果不建独立字段，由 hp 推导（hp>0 通关 / hp==0 未通关）。

game_type游戏模式文本通用 game_type 字段，0=故事 / 1=挑战（数字型文本）0 / 1通用
player_number游戏人数文本参与本局的玩家人数，1=单人 / 2=双人（数字型文本）1 / 2通用
level_id关卡ID文本具体关卡标识，1~18（数字型文本；关底萌可：1兔兔/2呼啦/3光明/4叮咚/5流浪/6动动/7贴贴/8熊熊/9缤缤·纷纷/10绵羊/11透明/12共共/13跳舞/14狐狐/15歌谣/16悄悄/17亲亲/18黑洞Boss）3通用

collecting星尘瓶数量数值本局收集星尘瓶总数（可求平均），复用通用 collecting「收集物数量」字段承载星尘瓶8通用
hp剩余生命点数数值通关时剩余生命点数（可求平均）。本页唯一标准外自定义字段；通关结果由此派生：hp>0 通关(成功)，hp==0 未通关(失败)3 / 0项目
📦 对象组字段：user_info 每个对象含 user_id（数值，裸数字）与 score（每名玩家得分，双人时分别看）；collecting / hp 为整局级，置于事件顶层。
user_info各角色数据对象组对象数组，每个对象包含 user_id（数值，裸数字）与 score（本局得分，数值）[{"user_id":135,"score":48},{"user_id":136,"score":35}]通用
user_info.user_id角色ID数值参与游戏的人脸角色ID（含 user_info 时只在对象组内出现，顶层不重复；裸数字，如 135，对齐示例）135必含
user_info.score本局得分数值该玩家本局累计得分（可求平均），双人时按 user_id 分别看48 / 35通用

玩家在关卡中触发暂停时上报（无 user_info，沿用顶层 user_id 列表）。
