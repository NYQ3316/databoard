enter_game（进入小游戏）
选定 12 个小游戏之一、本局开始时触发（支撑看板：活跃账号、近14天对局趋势、游玩性别统计；本局游玩时长由 end_game 与本事件的时间差派生）
属性名显示名类型说明示例来源
game_id游戏ID文本产品唯一编号1072必含
session_id会话ID文本本地生成 UUID v4（可不带横杠）；单局session_id保持一致，与对应 end_game 一致853b054e-1f29-4810-91d0-857471542101必含
timestamp时间戳时间事件发生时间（ISO8601，含时区+08:00）2026-05-26T09:35:10+08:00必含
game_type游戏模式文本本局训练模式（枚举待 CP 确认，暂定 0=默认模式）0通用
mini_game_id小游戏ID文本小游戏唯一标识（1~12，12 个游戏名称待 CP 提供）1通用
player_number游戏人数文本参与本局的玩家人数（1~2）1通用
📦 对象组字段：参与者信息封装在 user_info 对象组中（性别为账号级属性，进入小游戏时上报，统计端取各账号最新值做性别统计）。
user_info 参与者信息 对象组 对象数组，每个对象包含 user_id（文本）与 gender [{"user_id":135,"gender":0},{"user_id":136,"gender":1}] 项目特有
user_info.user_id↳ 人脸角色ID文本参与角色ID（JSON 值为裸数字，类型按文本统计）
游客按位置号上报：位置1=-1 / 位置2=-2 / 位置3=-3 / 位置4=-4		135项目特有
user_info.gender↳ 性别文本玩家性别（数值型文本）：0=男 / 1=女0项目特有
end_game（小游戏结束）
一个小游戏本局结束（通关 / 时间到 / 血量空 / 中途退出）时触发，承载本局全部结算数据（支撑看板：总对局数、游戏热度排名、结束原因构成、游戏详细数据表）
属性名显示名类型说明示例来源
game_id游戏ID文本产品唯一编号1072必含
session_id会话ID文本本地生成 UUID v4（可不带横杠）；单局session_id保持一致，与对应 enter_game 一致853b054e-1f29-4810-91d0-857471542101必含

📦 对象组字段：得分与操作错误为玩家级数据，封装在 user_info 对象组中（双人时逐角色各上报一条，user_info 内仅含本角色数据）；各体感动作的出现与错误明细单独封装在 action_info 对象组中。
user_info 参与者结算信息 对象组 对象数组，每个对象包含 user_id（文本）、mini_game_score、dda_level 与 answer_count [{"user_id":135,"mini_game_score":2360,"dda_level":17,"answer_count":7},{"user_id":136,"mini_game_score":1980,"dda_level":16,"answer_count":9}] 项目特有
user_info.user_id↳ 人脸角色ID文本参与角色ID（JSON 值为裸数字，类型按文本统计）
游客按位置号上报：位置1=-1 / 位置2=-2 / 位置3=-3 / 位置4=-4		135项目特有
user_info.mini_game_score↳ 小游戏得分数值该角色本局得分（多局可计算场均总得分）2360项目特有
user_info.dda_level↳ DDA 难度值数值该角色本局结束时 DDA 动态难度值（难度/目标数 N，数值越大难度越高，可求平均；双人按各自适应曲线独立取值）17项目特有
user_info.answer_count↳ 错误次数数值该角色本局操作错误累计次数（答错/识别失败），作为本局错误汇总数据；各动作明细见 action_info7项目特有
📦 动作明细对象组：action_info 为事件顶层独立对象组，对象内以 user_id 标识角色归属（双人时同一动作按角色各一行），每行记录一个角色一个动作的本局出现与错误明细；错误率与 Top3 动作由统计端排序派生，不上报统计值。
action_info 动作统计明细 对象组 对象数组，每个对象包含 user_id（文本）、action_id（文本）、appear_count 与 error_count [{"user_id":135,"action_id":1,"appear_count":42,"error_count":6},{"user_id":135,"action_id":3,"appear_count":38,"error_count":5},{"user_id":136,"action_id":1,"appear_count":40,"error_count":7}] 项目特有
action_info.user_id↳ 人脸角色ID文本该行动作明细归属的角色ID（JSON 值为裸数字，类型按文本统计）135项目特有
action_info.action_id↳ 动作ID文本体感动作唯一标识（动作编码表待 CP 提供：如拍击 / 挥臂 / 举臂 / 踏步 / 转身 / 抓取 / 投掷 / 深蹲 / 侧移）1项目特有
action_info.appear_count↳ 出现次数数值该角色该动作本局出现次数（错误率分母）42项目特有
action_info.error_count↳ 错误次数数值该角色该动作本局操作错误次数（错误率分子）6项目特有
⏱️ 时长口径：场均游玩时长不单独上报，由 end_game 与对应 enter_game 的 timestamp 差值派生（同一局 session_id 保持一致）。
