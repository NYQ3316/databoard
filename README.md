# databoard

数据看板与埋点命名规范仓库。

## 目录

### dashboards/ — 47 个项目的 Analytics Dashboard
### naming/ — 46 个项目的埋点命名规范
### naming_standards_standalone.html — 跨项目埋点命名统一标准（含项目导航）

## 访问方式

所有 HTML 文件通过 GitHub Pages 直接浏览：
- 看板：https://nyq3316.github.io/databoard/dashboards/{文件名}.html
- 命名规范总览：https://nyq3316.github.io/databoard/naming_standards_standalone.html
- 各项目命名：https://nyq3316.github.io/databoard/naming/{文件名}.html
