## 概述

本仓库包含 47 个游戏项目的 Analytics Dashboard（数据看板）以及跨项目埋点命名规范文档。

- **数据看板 (dashboards/)**：每个项目独立的 HTML 数据看板，覆盖了腾讯多个游戏（篮球火、猫爪特工、怪兽大乱斗、光能守护者、超级飞侠、蟹蟹大冒险 等）的关键事件埋点设计。
- **命名规范 (naming_standards_standalone.html)**：跨项目埋点命名标准文档，用于规范不同项目间的埋点命名约定。

## 使用方式

所有 HTML 文件均为独立可浏览文件，可直接通过浏览器打开查看，无需后端服务。
