🦓 1032《斑马百科》事件与属性命名

百科知识问答 · 单人 · 知识主题浏览 + 答题模块
enter_game（进入关卡）
玩家点击进入一个课程（知识主题 + 关卡）时触发，用于统计各主题访问量
属性名显示名类型说明示例来源
game_id游戏ID文本产品唯一编号1032必含
user_id 人脸角色ID 列表 参与角色ID，元素为文本类型 ["135"] 必含
session_id会话ID文本单次对局唯一标识s_987654321必含
timestamp时间戳时间事件发生时间（Unix毫秒）1748314800000必含
game_type知识主题文本当前课程的知识主题1（哺乳动物）/ 2（海洋生物）通用
level_id关卡ID文本课程下的关卡标识1 / 2 / 3通用
end_game（退出关卡）
玩家完整完成一个课程并正常退出时触发，收到此事件即视为通关。通过 enter_game 与 end_game 的事件数对比计算通关率。
属性名显示名类型说明示例来源

session_id会话ID文本单次对局唯一标识s_987654321必含
timestamp时间戳时间事件发生时间（Unix毫秒）1748314800000必含
game_type知识主题文本当前课程的知识主题1（哺乳动物）/ 2（海洋生物）通用
level_id关卡ID文本课程下的关卡标识1 / 2 / 3通用
quiz_start（答题回合开始）
一个答题回合开始时触发。一个课程可包含多个答题回合。

single_answer（单题作答结束）
每道题作答结束时逐题上报，用于汇总各知识主题下各关卡的答题正确率
属性名显示名类型说明示例来源

level_id关卡ID文本题目所属的关卡1 / 2 / 3通用
question_id题目ID文本单题唯一标识Q-2047通用
question_type题目类型文本题目所属类型记忆翻牌 / 逻辑排序通用
is_correct是否正确数值本次作答判定结果，1为对，0为错1 / 0通用
answer_count答错次数数值本回合截至当前题为止累计答错次数（答错时 +1，答对不累计）0 / 1 / 2 / 3项目特有
