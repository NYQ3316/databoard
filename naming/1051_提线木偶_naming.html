🪡 1051《提线木偶》事件与属性命名

体感平台跳跃 · 1~4人 · 挑战模式 / 竞赛模式 · 事件共 4 个
enter_game（进入游戏 / 关卡开始）
玩家选择模式（挑战/竞赛）、选择关卡/轮次并完成角色选择与准备后，正式开始比赛时触发
属性名显示名类型说明示例来源
game_id游戏ID文本产品唯一编号1051必含
user_id人脸角色ID列表所有参与角色ID，元素为文本类型["135","136"]必含
session_id会话ID文本单次对局唯一标识s_987654321必含
timestamp时间戳时间事件发生时间（Unix毫秒）1748314800000必含
game_type游戏模式文本挑战模式 / 竞赛模式0=挑战 / 1=竞赛通用
player_count游戏人数文本1~4 人1 / 2 / 3 / 4通用
level_id关卡ID文本挑战模式所选关卡，竞赛模式为空level_01（草地第1关）项目特有
round_count竞赛轮数文本竞赛模式所选轮次，挑战模式为空3 / 5 / 7通用
end_game（退出游戏 / 关卡结束）
挑战模式通关或失败 / 竞赛模式所有轮次结束时触发

📦 对象组字段：以下字段为封装在 user_info 对象组中的各角色结算数据， user_info 为对象数组，每个对象以 user_id（文本类型）标识角色。
user_info 各角色结算数据 对象组 对象数组，每个对象包含 user_id（文本）及各角色的结算数据 [{"user_id":135,"result":1,"total_score":850,"star_rating":3}] 项目特有
user_info.user_id↳ 角色ID文本该玩家的人脸角色标识135项目特有
user_info.result↳ 通关结果文本0=失败 / 1=通关成功0 / 1通用
user_info.total_score↳ 本局得分文本挑战模式得分 / 竞赛模式竞技场分数850通用
user_info.star_rating↳ 星星评价文本竞赛模式获胜星星数，挑战模式为空0 / 1 / 2 / 3通用
user_info.death_count↳ 死亡次数文本本局碰撞机关/敌人导致的失败次数2通用
